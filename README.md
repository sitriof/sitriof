## Proyectos Destacados

*   **Detección Multiespectral de Manglares**
    *   **Descripción:** Diseño e implementación de un pipeline de Machine Learning especializado en la detección de manglares a través de imágenes satelitales multiespectrales. Se aplicó análisis espectral y entrenamiento de modelos de clasificación (SVM, KNN, CART) para optimizar el monitoreo ambiental.
    *   **Tecnologías:** Python, Scikit-learn, Rasterio, Pandas.
    *   **Repositorio:** [github.com/sitriof/mangrove-detection-ml](https://github.com/sitriof/mangrove-detection-ml)

*   **Bolívar Rutas**
    *   **Descripción:** Aplicación web enfocada en el modelado de la red vial de los municipios del departamento de Bolívar. El sistema aplica teoría de grafos y algoritmos de optimización de redes para realizar cálculos precisos de rutas óptimas y flujo máximo.
    *   **Tecnologías:** Python, Flask, HTML, CSS, JavaScript, Google Maps API.
    *   **Repositorio:** [github.com/sitriof/bolivar-rutas](https://github.com/sitriof/bolivar-rutas)

*   **Sistema de Gestión para Barbería**
    *   **Descripción:** Solución de software de escritorio bajo arquitectura cliente-servidor diseñada para la administración integral de negocios. Incluye módulos para la gestión de citas, control de horarios, catálogo de servicios y administración de usuarios mediante una API REST local.
    *   **Tecnologías:** Node.js, Express.js, MongoDB, JavaScript.
    *   **Repositorio:** [github.com/sitriof/barbershop-system](https://github.com/sitriof/barbershop-system)

*   **Cartagena POI (Points of Interest)**
    *   **Descripción:** Plataforma web desarrollada para el análisis y la visualización interactiva de puntos de interés geográfico y turístico en la ciudad de Cartagena, estructurada estrictamente bajo el paradigma de Programación Orientada a Objetos.
    *   **Tecnologías:** HTML, JavaScript.
    *   **Repositorio:** [github.com/sitriof/cartagena-poi](https://github.com/sitriof/cartagena-poi)
